# 21 멀티트랙 지원 명세

## 1. 원칙

Brakepoint MVP는 Single Lap Viewer지만 Single Track Viewer가 아니다.

좌표가 있는 모든 LMU track/layout의 lap은 hardcoded track data 없이 표시되어야 한다.

## 2. MVP Requirement

MVP는 다음을 만족해야 한다.

- `trackName`과 `trackLayout`은 metadata로 표시한다.
- `trackName`이 없어도 session은 열 수 있어야 한다.
- 좌표가 있으면 어떤 트랙이든 fit-to-view로 표시한다.
- 좌표 범위를 하드코딩하지 않는다.
- SVG나 static track map은 source of truth가 아니다.
- 같은 `trackName`이라도 `trackLayout`이 다르면 다른 layout으로 취급한다.
- lap distance가 다르더라도 graph x-axis는 distance 기준으로 표시한다.

## 3. Canvas Fit-To-View Rule

Racing Line Viewer는 telemetry 좌표에서 bounding box를 계산한다.

필수 처리:

- minX / maxX / minY / maxY 계산
- aspect ratio 유지
- padding 적용
- canvas 밖으로 line이 잘리지 않게 표시
- track별 좌표 range 차이를 자동 처리

금지:

- Sebring/Fuji/Monza 등 특정 track의 좌표 범위 hardcoding
- SVG path 기반 fit-to-view
- track preset이 없으면 viewer를 막는 구조

## 4. Required Probe Coverage

Phase 1 전에 최소 다음 유형의 sample을 확인한다.

- 긴 트랙: Circuit de la Sarthe 또는 Spa
- 짧은 레이아웃: Sebring School Circuit
- 고속 트랙: Monza
- 복잡한 코너/고저차 트랙: Spa 또는 Portimão
- LMU 기본 트랙: Fuji

가능하면 이후 확인:

- Bahrain
- Portimão
- Circuit de la Sarthe
- DLC track 중 하나 이상

## 5. Failure Mode

| 상황 | 처리 |
| --- | --- |
| metadata 없음 | `Unknown Track`으로 표시 |
| trackLayout 없음 | layout 미확인 warning |
| 좌표 없음 | `distance-graph-only` |
| 좌표 confidence low | warning 표시 또는 graph-only |
| layout mismatch | Phase 2 이후 비교 기능 비활성화 |
| lap distance 없음 | lap analysis 실패 |

## 6. Phase 2 이후 필요 항목

Phase 2 이후부터는 다음 개념이 필요할 수 있다.

- TrackIdentity
- LayoutIdentity
- Track length validation
- Lap closure validation
- Per-track coordinate orientation
- Per-layout cached normalization
- Segment naming
- Corner naming
- Reference lap matching

MVP에서는 이 개념을 구현하지 않는다.

## 7. 현재 조사 결과

`19_DuckDB_조사_결과_샘플.md` 기준으로 다음 트랙에서 좌표와 distance가 확인됐다.

- Spa
- Fuji
- Sebring School Circuit
- Monza

따라서 Phase 1의 multi-track by design 조건은 구현 가능성이 높다.

## 8. Acceptance Criteria

- 서로 다른 track/layout 2개 이상에서 racing line이 canvas 안에 표시된다.
- 긴 track과 짧은 layout 모두 graph x-axis가 distance 기준으로 표시된다.
- track preset 없이 좌표 기반 fit-to-view가 동작한다.
- metadata가 없어도 좌표가 있으면 viewer는 동작한다.
