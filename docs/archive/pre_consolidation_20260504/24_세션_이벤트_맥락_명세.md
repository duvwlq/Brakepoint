# 24 세션 이벤트 맥락 명세

## 1. 목적

Practice, Qualifying, Race, 온라인 이벤트, hosted server 등 session context를 구조화한다.

이 정보는 Phase 1에서는 표시용이고, Phase 2 이후 비교/분석의 안전장치로 사용한다.

## 2. SessionType

```ts
type SessionType =
  | 'practice'
  | 'qualifying'
  | 'race'
  | 'test-day'
  | 'unknown'
```

## 3. EventType

```ts
type EventType =
  | 'offline-race-weekend'
  | 'racecontrol-daily'
  | 'racecontrol-weekly'
  | 'racecontrol-special'
  | 'racecontrol-championship'
  | 'hosted-server'
  | 'unknown'
```

## 4. LapKind

```ts
type LapKind =
  | 'out-lap'
  | 'flying-lap'
  | 'in-lap'
  | 'race-lap'
  | 'invalid'
  | 'unknown'
```

## 5. MVP 처리

Phase 1에서 필수:

- SessionType 표시
- unknown session type fallback
- invalid lap 표시

Phase 1에서 선택:

- In Pits event를 이용한 in/out lap 후보 표시

Phase 1에서 금지:

- RaceControl Daily/Weekly/Special을 추측으로 분류
- 트래픽/연료/타이어 맥락을 분석 판단에 사용

## 6. 분석 주의점

실제 race lap은 hotlap/qualifying lap과 다르다.

Race lap에는 다음 변수가 있다.

- traffic
- multi-class overtake
- fuel load
- tire state
- track grip
- weather
- pit in/out
- blue/yellow flag
- accident avoidance

따라서 Phase 5 Coach UX에서 race lap을 qualifying lap처럼 단순 비교하면 안 된다.

## 7. Unknown 처리

event context가 없으면:

- `eventType = 'unknown'`
- UI에는 추측하지 않고 "Event context unknown" 표시
- 분석 판단에는 사용하지 않음
