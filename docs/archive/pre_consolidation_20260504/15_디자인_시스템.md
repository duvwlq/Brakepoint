# 15 Design System

## 1. Direction

Brakepoint는 LMU inspired 디자인을 사용한다. 단, 공식 LMU 앱처럼 보이면 안 된다.

원칙:

```text
LMU inspired, not LMU branded.
```

## 2. Color Tokens

| Token | Purpose | Hex |
| --- | --- | --- |
| `background` | App background | `#0B0F14` |
| `panel` | Panel background | `#121821` |
| `primary` | Brand accent / selected state | `#E60442` |
| `brake` | Brake / danger / loss | `#EB2622` |
| `throttle` | Throttle / data blue | `#447FBC` |
| `secondaryBlue` | Secondary data | `#447FBC` |
| `darkBlue` | Racing blue accent | `#0A4E99` |
| `deepIndigo` | Muted line / inactive data | `#424B78` |
| `softBlue` | Ghost / secondary text | `#91B4D4` |
| `textPrimary` | Main text / active core | `#F6F7F7` |

## 3. Semantic Usage

### Primary

사용자가 현재 보고 있는 핵심 상태, 선택 지점, hover sync cursor에 사용한다.

### Red

Brake, loss, danger, 강한 입력, warning emphasis에 사용한다.

### Blue

Throttle, secondary data, stable state, ghost-like supporting data에 사용한다.

### White

Current lap의 핵심 line과 active point에 사용한다.

### Deep Indigo

비활성 line, background track, low confidence data에 사용한다.

## 6. Accessibility Rule

색상만으로 의미를 전달하지 않는다.

Brake와 throttle은 다음 요소를 함께 사용한다.

- label
- tooltip value
- line width
- marker shape
- legend

## 7. Brand Safety

금지:

- LMU 로고 사용
- 공식 LMU 앱처럼 보이는 화면 구성
- 공식 명칭처럼 오해될 수 있는 문구

허용:

- 레이싱 톤의 red/blue/white/dark palette
- telemetry 분석 도구다운 compact dashboard style
