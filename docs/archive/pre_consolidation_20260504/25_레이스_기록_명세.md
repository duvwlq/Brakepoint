# 25 레이스 기록 명세

## 1. 목적

Race Records는 실제 레이스가 끝난 뒤 결과를 요약하는 탭이다.

MVP 핵심 기능은 아니며, DuckDB에 race result 데이터가 확인된 뒤 Phase 1.5 또는 Phase 2에서 검토한다.

## 2. RaceResult

```ts
type RaceResult = {
  overallPosition?: number
  classPosition?: number
  gridPosition?: number
  finishStatus?: 'finished' | 'dnf' | 'dsq' | 'unknown'
  totalLaps?: number
  completedLaps?: number
  raceTimeMs?: number
  gapToWinnerMs?: number
  source: 'telemetry-event' | 'derived' | 'manual' | 'unknown'
  confidence: 'high' | 'medium' | 'low'
}
```

## 4. Source Rule

Race result는 추측하지 않는다.

표시 조건:

- DuckDB event/metadata에서 직접 확인
- 또는 명확한 파생 규칙이 문서화됨

정보가 없으면:

```text
Race result data not available
```

## 5. Overall vs Class Position

LMU는 멀티클래스 레이스가 많으므로 overall position과 class position을 분리한다.

예:

```text
Overall: P12
Class: P2
```

## 6. MVP Boundary

Phase 1에서 Race Records tab을 구현하지 않는다.

Phase 1에서 할 것:

- Race session임을 표시
- carName / carClass 표시
- lap list 표시

Phase 1에서 하지 않을 것:

- 순위 추정
- class position 추정
- race result card 표시
