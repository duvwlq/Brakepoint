# 28 게임 어댑터 계약

## Goal

모든 game adapter가 제공해야 하는 기능과 반환 모델을 정의한다.

## Contract

```ts
export type GameAdapter = {
  gameId: GameId
  displayName: string

  detectSources(): Promise<GameDataSource[]>

  probe(source: GameDataSource): Promise<GameProbeReport>

  listSessions(source: GameDataSource): Promise<NormalizedSessionSummary[]>

  loadSession(
    source: GameDataSource,
    sessionId: string
  ): Promise<NormalizedSessionDetail>

  loadLapTelemetry(
    source: GameDataSource,
    sessionId: string,
    lapId: string
  ): Promise<NormalizedLapTelemetry>

  getCapabilities(): GameCapabilities
}
```

## Responsibilities

- source detection
- read-only probe
- raw session discovery
- unit normalization
- coordinate normalization
- distance mapping
- warning/fallback generation
- capability report

## Adapter Boundary

Adapter 안에서는 raw schema를 알아도 된다.

Adapter 밖에서는 canonical model만 사용한다.

## Phase 1 Adapter

Phase 1에서 구현할 adapter:

- `lmuDuckdbAdapter`

구현하지 않을 adapter:

- `f1UdpAdapter`
- `assettoSharedMemoryAdapter`
- `accAdapter`
- `iracingSdkAdapter`

## Fallback Rule

- distance 없음: comparison, ghost, coach 비활성화
- coordinates 없음: racing line 비활성화, graph-only fallback
- lap time 없음: invalid lap
- car/track metadata 없음: unknown 표시
