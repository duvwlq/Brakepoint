# 03 User Flows

## 1. MVP Flow

```text
앱 실행
-> telemetry 폴더 확인
-> session 목록 표시
-> session 선택
-> metadata / lap 목록 표시
-> valid lap 선택
-> 좌표 channel 확인
-> Racing Line Viewer 표시 또는 fallback 표시
```

## 2. Home / Session List

사용자는 앱 실행 후 다음을 알아야 한다.

- LMU telemetry 폴더를 찾았는가?
- `.duckdb` 파일이 있는가?
- 어떤 session이 최신인가?
- 읽을 수 없는 session이 있는가?

## 3. Session Detail / Lap List

사용자는 session 선택 후 다음을 알아야 한다.

- 어떤 track / layout인가?
- 어떤 차량인가?
- valid lap은 몇 개인가?
- invalid lap은 왜 선택할 수 없는가?
- Best Lap은 무엇인가?
- 좌표 데이터가 있을 가능성이 있는가?

## 4. Racing Line Viewer

사용자는 lap 선택 후 다음을 알아야 한다.

- 현재 보고 있는 lap 번호
- 현재 data mode가 실제 좌표 기반인지 graph-only fallback인지
- 현재 hover 지점의 distance
- 어디서 brake / throttle이 발생했는지

## 5. Fallback Flow

좌표가 없으면 다음 흐름을 따른다.

```text
lap 선택
-> 좌표 channel 없음
-> Racing Line 대신 fallback message 표시
-> Speed / Brake / Throttle graph는 가능하면 표시
```

## 6. Error Flow

```text
file read 실패
-> 앱 종료 금지
-> 해당 session만 error 상태 표시
-> 사용자는 다른 session을 계속 열 수 있음
```

## 7. Invalid Lap Flow

```text
Lap Time 없음 또는 0 이하
-> invalid lap으로 표시
-> lap 선택 비활성화
-> reason 표시
```
