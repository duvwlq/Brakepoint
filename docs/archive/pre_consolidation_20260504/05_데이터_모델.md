# 05 데이터 모델

## 1. 원칙

- MVP 데이터 모델의 중심은 실제 telemetry 좌표와 distance다.
- Phase 1 구현은 LMU에 집중하지만, core model은 multi-game-ready로 유지한다.
- 게임별 raw field 이름은 UI model에 직접 노출하지 않는다.
- API는 `ApiResult<T>` 형태로 성공/실패를 명확히 반환한다.

## 3. API Result

```ts
export type ApiResult<T> =
  | { ok: true; data: T }
  | { ok: false; error: ApiError }

export type ApiError = {
  code: ApiErrorCode
  message: string
  detail?: string
}

export type ApiErrorCode =
  | 'TELEMETRY_FOLDER_MISSING'
  | 'FILE_UNREADABLE'

  | 'UNKNOWN_ERROR'
```
