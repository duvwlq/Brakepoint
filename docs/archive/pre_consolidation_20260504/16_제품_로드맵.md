# 16 제품 로드맵

## Roadmap Rule

Brakepoint는 MVP 이후 방향까지 설계한다.

하지만 개발은 Phase Gate를 통과한 기능만 진행한다.

```text
로드맵은 크게.
구현은 게이트별로.
```

## Phase 0. Research & Product Lock

### Goal

아이디어와 실제 LMU telemetry 데이터가 충돌하지 않게 만든다.

### Includes

- LMU telemetry 자료조사
- DuckDB schema probe
- 좌표 channel 검증
- 디자인 시스템 확정
- Idea/Data Alignment Matrix
- Phase Gate 정의
- ADR 정리
- canonical telemetry model 문서화
- Game Adapter contract 문서화

### User Value

사용자가 직접 느끼는 기능은 없지만, 이후 기능이 실제 데이터 위에 안정적으로 올라가게 한다.

## Phase 1. Single Lap Racing Line Viewer

### Goal

내가 실제로 어떻게 달렸는지 본다.

### Includes

- LMU DuckDB adapter
- Session list
- Lap list
- Coordinate detection
- 실제 racing line
- Speed / Brake / Throttle graph
- Hover sync
- Fallback mode
- multi-track by design

### User Value

"내가 이 랩에서 어떤 라인으로 달렸는지"를 한눈에 본다.

## Phase 1.5. Race Records Candidate

### Goal

Race session 기록을 요약할 수 있는지 검증한다.

### Gate

RaceResult가 DuckDB에 직접 있거나 명확하게 파생 가능한 경우에만 진행한다.

### Rule

결과는 추측하지 않는다.

## Phase 2. Best Lap Comparison

### Goal

내 lap과 Best Lap을 같은 distance 기준으로 비교한다.

### Required Data

- current lap racing line
- best lap racing line
- distance alignment
- speed/brake/throttle resampling
- lap delta

### Failure Mode

좌표가 불안정하면 line comparison이 아니라 graph comparison만 제공한다.

## Phase 3. Ghost Replay

### Goal

두 차량이 같은 distance 기준으로 움직이며 차이를 보여준다.

### Required Data

- distance-indexed current lap
- distance-indexed best lap
- interpolation
- playhead
- delta time

### Rule

Replay 기준은 time이 아니라 distance다.

## Phase 4. Difference Analysis

### Goal

어디서 다른지만 보여주는 것이 아니라 왜 느린지 보여준다.

### Includes

- brake start difference
- throttle reapply difference
- min speed difference
- exit speed difference
- line deviation
- segment based summary

### Gate

비교 지표가 실제 사용자가 납득 가능한 수준이어야 한다.

## Phase 5. Coach UX

### Goal

다음 랩에서 무엇을 바꿀지 알려준다.

### Rule

AI보다 rule-based coach가 먼저다.

판단의 source of truth는 telemetry다.

## Phase 6. Track Envelope / Multi-Lap Learning

### Goal

여러 lap의 좌표 데이터를 누적해 주행 가능 영역과 line 분포를 만든다.

### Includes

- multi-lap overlay
- track envelope estimation
- common racing corridor
- line consistency score

## Phase 7. Adapter-Based Game Expansion

### Goal

LMU MVP가 안정화된 뒤 다른 racing game telemetry source를 Game Adapter 방식으로 추가한다.

### Candidate Games

- F1 25
- Assetto Corsa
- Assetto Corsa Competizione
- iRacing

### Rule

새 게임 지원은 새 앱 구조를 만들지 않는다.

새 Game Adapter와 mapping manifest를 추가한다.

### Required Work

- game telemetry source 조사
- GameCapabilities 작성
- canonical model mapping 검증
- live recorder 필요 여부 판단
- legal/API 제한 확인
- fallback policy 정의

### Forbidden Before Gate

- F1/AC/iRacing adapter 구현
- cross-game comparison
- raw packet/shared-memory field를 UI에 직접 노출

## Current Development Position

현재 위치는 Phase 0이다.

다음 개발은 전체 앱 구현이 아니라 LMU DuckDB data layer와 probe 기반 Phase 1 준비다.
