# 30 게임 지원 조사 계획

## Goal

Phase 7 이전에 추가 게임 지원 가능성을 조사한다.

현재 구현 대상은 아니다.

## Candidate Games

- F1 25
- Assetto Corsa
- Assetto Corsa Competizione
- iRacing

## Research Questions

각 게임별로 다음을 조사한다.

- telemetry source
- live/post-session 여부
- 좌표 가능 여부
- distance 가능 여부
- lap result 가능 여부
- race result 가능 여부
- car metadata
- track metadata
- legal/API 제한
- recorder 필요 여부
- 저장 포맷
- canonical model mapping 가능 여부

## Live Capture Rule

UDP/shared memory/SDK 기반 게임은 UI가 live source를 직접 보지 않는다.

권장 흐름:

```text
Live source
  -> Game Adapter
  -> Raw log
  -> Normalized Brakepoint Session Store
  -> Analysis UI
```

## Cross-Game Comparison

기본 금지.

나중에 지원하더라도 "정확한 분석"이 아니라 "참고 비교"로 분리한다.

## Phase 7 Entry

새 게임은 다음 조건을 만족해야 한다.

- Game Adapter probe 가능
- GameCapabilities 작성
- canonical model mapping 가능
- fallback 정책 존재
- legal/API 제한 확인
