# 23 차량 지원 명세

## 1. 목적

Brakepoint는 Le Mans Ultimate의 다양한 차량과 클래스를 metadata context로 구조화한다.

차량 구조화는 나중에 Best Lap 비교, leaderboard, Coach UX가 잘못된 기준으로 동작하지 않게 하기 위한 기반이다.

## 2. 원칙

- 공식 차량 목록은 참고 catalog다.
- source of truth는 telemetry metadata와 DuckDB probe 결과다.
- 처음부터 지원 차량 목록을 하드코딩하지 않는다.
- 실제 session에서 발견한 차량을 observed car catalog로 누적할 수 있게 설계한다.
- `carName` 원본 문자열은 절대 버리지 않는다.

## 3. CarIdentity

```ts
type GameId = 'lmu'

type CarClass =
  | 'Hypercar'
  | 'LMGT3'
  | 'LMP2'
  | 'LMP3'
  | 'GTE'
  | 'unknown'

type CarIdentity = {
  game: GameId
  carId: string
  rawName?: string
  displayName: string
  carClass: CarClass
  manufacturer?: string
  model?: string
  season?: string
  dlc?: boolean
  source: 'telemetry-metadata' | 'official-catalog' | 'manual' | 'unknown'
  confidence: 'high' | 'medium' | 'low'
}
```

## 4. Comparison Compatibility Rule

Brakepoint는 서로 다른 조건의 lap을 무조건 비교하지 않는다.

기본 비교 가능 조건:

- 같은 game
- 같은 trackName
- 같은 trackLayout
- 같은 carId 또는 최소 같은 carClass
- distance alignment 가능
- valid lap
- coordinate confidence가 high 또는 medium

다음 경우에는 기본 비교를 막거나 warning을 표시한다.

- 다른 차량
- 다른 클래스
- 다른 track layout
- race lap vs qualifying lap
- out lap / in lap
- 좌표 confidence low
- distance missing

## 5. MVP 처리

Phase 1에서는 차량 기반 분석을 하지 않는다.

Phase 1에서 할 것:

- carName 표시
- carClass 표시
- unknown car fallback 표시
- 원본 metadata 보존

Phase 1에서 하지 않을 것:

- 차량별 코칭
- 차량별 기준치
- 차량별 leaderboard
- 다른 차량 비교 자동 허용

## 6. Unknown 처리

차량 정보가 없거나 정규화할 수 없으면:

- `displayName = 'Unknown Car'`
- `carClass = 'unknown'`
- `confidence = 'low'`
- lap viewer는 가능한 경우 계속 동작
