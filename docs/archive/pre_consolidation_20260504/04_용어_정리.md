# 04 Domain Glossary

## Brakepoint

LMU telemetry 기반 실제 주행 라인 시각화 앱.

## Telemetry File

Le Mans Ultimate가 생성한 `.duckdb` 파일.

## Session

하나의 telemetry 파일에 해당하는 주행 기록 단위.

## Lap

Session 안의 개별 랩.

## Valid Lap

Lap Time이 존재하고 0보다 큰 완료 랩.

## Invalid Lap

Lap Time이 없거나 0 이하이거나 완료되지 않은 랩.

## Best Lap

Valid lap 중 lap time이 가장 짧은 랩. MVP에서는 표시할 수 있지만 비교 기준으로 사용하지 않는다.

## Distance

랩 시작 지점부터의 거리. Brakepoint의 모든 hover, graph, replay 동기화 기준.

## Racing Line

XY/GPS 좌표 기반 실제 주행 궤적.

## Distance Graph Only Mode

좌표 데이터는 없지만 distance, speed, brake, throttle data가 있어 graph만 표시하는 fallback mode.

## SVG Track

시각 참고용 트랙 그림. MVP에서는 source of truth가 아니며 실제 track width, boundary, racing line 계산 기준으로 사용하지 않는다.

## Coordinate Detection

DuckDB channel에서 실제 주행 좌표로 사용할 수 있는 X/Y, X/Z, GPS pair를 찾는 과정.

## Coordinate Confidence

좌표 후보가 실제 racing line으로 신뢰 가능한 정도. `high`, `medium`, `low`, `none`으로 표시한다.

## Data Mode

현재 lap viewer가 어떤 데이터 방식으로 표시되는지 나타내는 상태.

- `real-racing-line`: 실제 좌표 기반 racing line
- `distance-graph-only`: 좌표 없음, graph only fallback

## Data Warning

좌표 없음, sample 부족, partial channel 등 사용자가 알아야 할 데이터 품질 문제.
