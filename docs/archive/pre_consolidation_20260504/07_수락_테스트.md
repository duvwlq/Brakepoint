# 07 Acceptance Tests

## AT-001. Telemetry Folder Status

Given 앱이 실행된다.  
When telemetry folder status를 확인한다.  
Then 현재 folder path, 존재 여부, 파일 수를 표시한다.

## AT-002. Session List

Given telemetry folder에 `.duckdb` 파일이 있다.  
When session list를 로드한다.  
Then `.duckdb.wal` 파일은 제외하고 `.duckdb` 파일만 최신순으로 표시한다.

## AT-003. Session Metadata

Given 사용자가 session을 선택한다.  
When metadata를 읽는다.  
Then TrackName, TrackLayout, SessionType, CarName 중 가능한 값을 표시한다.

## AT-004. Lap List

Given 사용자가 session을 선택한다.  
When Lap event와 Lap Time event를 읽는다.  
Then valid/invalid lap 목록과 best lap 표시가 생성된다.

## AT-005. Coordinate Detection

Given 사용자가 valid lap을 선택한다.  
When coordinate channel detection을 실행한다.  
Then XY/GPS 좌표 사용 가능 여부와 confidence를 표시한다.

## AT-006. Racing Line Viewer

Given 좌표가 있는 valid lap이 선택된다.  
When Racing Line Viewer가 열린다.  
Then 실제 좌표 기반 racing line이 canvas 안에 표시된다.

## AT-007. Hover Sync

Given Racing Line Viewer와 graph가 표시된다.  
When 사용자가 line 또는 graph 위에 hover한다.  
Then 동일한 distance 위치가 canvas와 graph에 함께 표시된다.

## AT-008. Coordinate Missing Fallback

Given 좌표가 없는 lap이 선택된다.  
When Racing Line Viewer를 열려고 한다.  
Then 가짜 트랙맵을 만들지 않고 `distance-graph-only` mode와 fallback 메시지를 표시한다.

## AT-009. File Read Failure

Given telemetry folder에 손상되었거나 읽을 수 없는 `.duckdb` 파일이 있다.  
When session list를 로드한다.  
Then 앱은 종료되지 않고 해당 파일만 error 상태로 표시한다.

## AT-010. Invalid Lap Disabled

Given Lap Time이 없거나 0 이하인 lap이 있다.  
When lap list를 표시한다.  
Then invalid lap은 선택할 수 없고 invalid reason을 표시한다.

## AT-011. Distance Graph Only Mode

Given 좌표는 없지만 distance, speed, brake, throttle 데이터가 있다.  
When 사용자가 valid lap을 선택한다.  
Then racing line 대신 fallback 메시지를 표시하고 가능한 graph를 표시한다.

## AT-012. Canvas Fit To View

Given 좌표가 있는 valid lap을 선택한다.  
When Racing Line Viewer가 열린다.  
Then 전체 racing line이 canvas 영역 안에 잘리지 않고 표시된다.

## AT-013. Data Mode Badge

Given Racing Line Viewer가 열린다.  
When 좌표 기반 데이터가 표시된다.  
Then 사용자는 현재 데이터가 실제 XY/GPS 기반인지 즉시 알 수 있다.

## AT-014. Partial Channel Warning

Given throttle 또는 brake 채널 일부가 없다.  
When lap telemetry를 로드한다.  
Then 가능한 데이터는 표시하고 누락된 채널 warning을 표시한다.

## AT-015. No Fake Track Map

Given 좌표 데이터가 없고 layout source도 확정되지 않았다.  
When lap을 분석한다.  
Then 앱은 SVG나 임의 path를 실제 트랙처럼 표시하지 않는다.

## AT-016. Car Metadata Display

Given session metadata에 carName 또는 carClass가 있다.  
When session detail을 표시한다.  
Then 사용자는 차량명과 차량 클래스를 볼 수 있다.

## AT-017. Unknown Car Fallback

Given 차량 정보를 찾을 수 없다.  
When session detail을 표시한다.  
Then 앱은 `Unknown Car`로 표시하고 lap viewer는 가능한 경우 계속 동작한다.

## AT-018. Race Session Metadata

Given sessionType이 Race로 기록되어 있다.  
When session detail을 표시한다.  
Then 앱은 해당 session이 Race session임을 표시한다.

## AT-019. Race Result Availability

Given race result 정보가 기록되어 있다.  
When Race Records tab을 연다.  
Then overall position, class position, completed laps 중 가능한 정보를 표시한다.

## AT-020. Race Result Missing

Given race result 정보가 없다.  
When Race Records tab을 연다.  
Then 앱은 추측하지 않고 `Race result data not available` 상태를 표시한다.
