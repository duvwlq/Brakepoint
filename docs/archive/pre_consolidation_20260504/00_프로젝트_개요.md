# 00 Project Brief

## 1. 프로젝트 이름

Brakepoint

## 2. 한 줄 설명

Brakepoint는 Le Mans Ultimate `.duckdb` telemetry 파일에서 실제 XY/GPS 주행 좌표를 추출해, 사용자가 자신의 단일 랩 주행 라인을 한눈에 이해할 수 있게 하는 데스크톱 앱이다.

## 3. 해결하려는 문제

일반 사용자는 telemetry graph를 직접 해석하기 어렵다.

특히 다음 질문을 바로 이해하기 어렵다.

- 내가 실제로 어떤 라인으로 달렸는가?
- 어디서 브레이크를 밟았는가?
- 어디서 스로틀을 열었는가?
- 좌표 데이터가 있는 세션과 없는 세션을 어떻게 구분해야 하는가?

Brakepoint MVP는 코칭 문장이나 비교 분석보다 먼저, 사용자가 자신의 실제 주행 라인을 볼 수 있게 만든다.

## 4. 대상 사용자

- Le Mans Ultimate를 플레이하는 일반 유저
- 자신의 랩을 시각적으로 보고 싶은 유저
- MoTeC 같은 전문 도구가 부담스러운 유저
- 기록을 줄이고 싶지만 telemetry 해석 경험이 적은 유저

## 5. 제품 원칙

### Principle 1. Telemetry First

실제 telemetry XY/GPS 좌표가 source of truth다.

### Principle 2. SVG는 보조 자료

SVG는 실제 트랙 폭, 경계, 주행 좌표를 보장하지 않으므로 MVP 핵심 데이터로 사용하지 않는다.

### Principle 3. Distance Sync

모든 graph, hover, replay 동기화 기준은 distance다.

### Principle 4. MVP는 작게

초기 MVP는 Single Lap Racing Line Viewer에 집중한다.

## 6. 현재 결정

- Electron + React + TypeScript를 사용한다.
- DuckDB parsing은 별도 data layer에서 처리한다.
- Canvas는 racing line 렌더링에만 사용한다.
- Recharts는 Speed / Brake / Throttle graph에만 사용 가능하다.
- Coach / Ghost / Heatmap / AI는 MVP 이후 단계로 미룬다.
