# 17 Idea Data Alignment Matrix

## Goal

좋은 아이디어라도 실제 telemetry 데이터가 뒷받침되지 않으면 구현하지 않는다.

모든 기능 아이디어는 이 문서를 통과해야 한다.

## Required Fields

| Field | Question |
| --- | --- |
| User Value | 이 기능이 사용자의 어떤 질문에 답하는가? |
| Required Data | 이 기능에 필요한 telemetry 데이터는 무엇인가? |
| Data Confirmed? | 실제 `.duckdb`에서 확인했는가? |
| Data Quality | sample count, null, 단위, 좌표 안정성은 어떤가? |
| Algorithm | 어떤 계산이 필요한가? |
| UI Output | 화면에 무엇으로 보여줄 것인가? |
| Failure Mode | 데이터가 없으면 어떻게 fallback할 것인가? |
| Phase | 어느 단계에 넣을 것인가? |
| Acceptance Criteria | 완료 기준은 테스트 가능한가? |

| Idea | User Value | Required Data | Data Confirmed? | Failure Mode | Phase | Status |
| --- | --- | --- | --- | --- | --- | --- |

## Rule

`Data Confirmed?`가 `No` 또는 `Needs Research`인 기능은 구현하지 않는다.

문서화는 가능하지만 implementation task로 만들 수 없다.
