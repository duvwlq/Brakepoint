# 10 UI Rules

## 1. 화면 원칙

MVP의 중심은 Racing Line Canvas다.

Graph는 보조 정보다.

## 2. 표시 우선순위

1. Racing Line 또는 fallback 상태
2. Lap / Track / Data Mode
3. Speed / Brake / Throttle graph
4. Coordinate confidence
5. Data warnings

## 3. 색상

색상은 `15_디자인_시스템.md`의 design token을 따른다.

- Background: `#0B0F14`
- Panel: `#121821`
- Primary / Brand Accent: `#E60442`
- Brake / Danger / Loss: `#EB2622`
- Throttle / Data Blue: `#447FBC`
- Dark Blue Accent: `#0A4E99`
- Deep Indigo / Muted Line: `#424B78`
- Soft Blue / Ghost / Secondary Text: `#91B4D4`
- Text Primary: `#F6F7F7`

## 4. Racing Line 색상

- Current Lap base line: `#F6F7F7`
- Brake strong zone: `#EB2622`
- Throttle strong zone: `#447FBC`
- Active hover point: `#F6F7F7` core + `#E60442` ring
- Selected point: `#E60442`
- Low confidence line: `#424B78`

## 5. Graph 색상

- Speed: `#F6F7F7` 또는 `#91B4D4`
- Brake: `#EB2622`
- Throttle: `#447FBC`
- Steering: `#91B4D4`
- Cursor / Hover Sync: `#E60442`
- Grid line: `#424B78` 낮은 opacity

## 6. Data Mode Badge

Racing Line Viewer에는 항상 data mode badge를 표시한다.

예시:

```text
Real Racing Line (XY/GPS)
```

```text
Distance Graph Only
```

## 7. Warning Banner

데이터 품질 문제가 있으면 canvas 상단 또는 graph 상단에 명확한 warning을 표시한다.

예시:

```text
Coordinate Data Missing: 이 세션에는 실제 XY/GPS 좌표가 없어 주행 라인을 표시할 수 없습니다.
```

```text
Partial Channels: Brake channel이 없어 Speed/Throttle graph만 표시합니다.
```

## 8. Fallback

좌표가 없으면 명확하게 말한다.

금지:

- 가짜 트랙맵 표시
- SVG를 실제 주행 경계처럼 표시
- 좌표가 없는데 racing line처럼 보이게 표시

허용:

- fallback message
- 가능한 Speed / Brake / Throttle graph
- data warning

## 9. UX 문장

전문 용어보다 사용자가 이해할 수 있는 문장을 우선한다.

좋은 예:

```text
이 랩은 실제 XY 좌표로 표시됩니다.
```

```text
이 세션에는 좌표 데이터가 없어 주행 라인은 표시할 수 없습니다.
```

## 10. Brand Rule

Brakepoint는 LMU inspired 디자인을 사용하지만 공식 LMU 앱처럼 보이면 안 된다.

금지:

- LMU 로고 사용
- 공식 LMU 앱으로 오해될 수 있는 문구
- 공식 UI를 그대로 복제한 화면 구성
