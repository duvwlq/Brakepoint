# 27 표준 텔레메트리 모델

## Goal

Brakepoint 내부에서 사용하는 공통 Session, Lap, TelemetryPoint, TrackIdentity, CarIdentity, RaceResult 모델을 정의한다.

Raw game field 이름은 이 문서에 들어오지 않는다.

## Canonical Model

핵심 모델은 `05_데이터_모델.md`를 따른다.

주요 타입:

- `GameId`
- `DataSourceKind`
- `TrackIdentity`
- `CarIdentity`
- `NormalizedSessionSummary`
- `NormalizedLapSummary`
- `NormalizedTelemetryPoint`
- `NormalizedLapTelemetry`
- `SyncStatus`
- `CoordinateStatus`
- `GameCapabilities`

## Sync Rule

Distance가 high/medium confidence면 다음 기능을 허용할 수 있다.

- Racing line hover
- graph hover
- comparison
- replay

Distance가 없으면:

- time graph only 또는 sample graph only
- Best Lap comparison 비활성화
- Ghost 비활성화
- Coach 비활성화

## Coordinate Rule

UI는 x/y만 받는다.

게임별 X/Z, GPS, world coordinate 변환은 Adapter/Domain Layer에서 끝낸다.

## Cross-Game Rule

서로 다른 game의 lap은 기본 비교하지 않는다.

cross-game reference comparison은 Phase 7 이후 별도 연구 항목이다.
