# 11 Release Plan

## 1. MVP Release

목표:

Single Lap Racing Line Viewer가 안정적으로 동작하는 첫 배포.

## 2. MVP Freeze Checklist

MVP 배포 전 다음 항목을 만족해야 한다.

- Phase 0 Exit Gate 통과
- DuckDB probe 결과 반영
- design token 확정
- Best Lap 비교 구현 없음
- Ghost 구현 없음
- Coach 구현 없음
- Heatmap 구현 없음
- AI 구현 없음
- SVG를 source of truth로 사용하지 않음
- 좌표 없음 fallback 명확
- API contract와 data model 고정

## 3. Release Checklist

- typecheck 통과
- build 통과
- packaged app 실행
- telemetry folder status 확인
- session list 확인
- lap list 확인
- coordinate detection 확인
- racing line viewer 확인
- coordinate missing fallback 확인
- file read failure 확인
- invalid lap disabled 확인

## 4. Research Checklist

MVP 개발 전 확인해야 한다.

- 실제 `.duckdb` table list 확인
- metadata 위치 확인
- Lap / Lap Time event 확인
- distance channel 확인
- speed/brake/throttle channel 확인
- coordinate 후보 channel 확인
- 좌표 없음 fallback sample 확인
- file read failure sample 확인
- invalid lap sample 확인 또는 test fixture 정의

## 5. Phase Gate

Release는 `18_페이즈_게이트.md`의 Phase 1 기준을 충족해야 한다.

MVP 이후 기능은 roadmap에 있어도 Phase Gate 통과 전에는 구현하지 않는다.

## 6. Rollback

문제 발생 시 이전 release folder를 사용한다.

## 7. Known Non-MVP

다음은 MVP release에 포함하지 않는다.

- Best Lap comparison
- Ghost
- Coach
- Heatmap
- AI
