# ADR-0001. Telemetry First

## Status

Accepted

## Context

Brakepoint는 사용자의 실제 주행 라인을 보여주는 앱이다. SVG track image는 시각적으로 그럴듯해 보일 수 있지만 실제 트랙 폭, 경계, 물리 좌표를 보장하지 않는다.

## Decision

Brakepoint MVP의 source of truth는 LMU `.duckdb` telemetry 내부의 XY/GPS 좌표다.

## Consequences

- 좌표가 있으면 실제 주행 라인을 표시한다.
- 좌표가 없으면 가짜 racing line을 만들지 않는다.
- SVG는 실제 트랙 경계나 racing line 계산 기준으로 사용하지 않는다.
- Coordinate detection 실패 시 fallback mode로 진입한다.
